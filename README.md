## What it does

```bash
cargo run --bin ayeos-matrix 256 64
# ayeOS matrix — LINOSV seed (SHA-256: 67dc0028cfe67ab7...)
# 256×256 matrix, 12.80x compression, 7.7% sparsity
# Same matrix every time. Deterministic. Reproducible.

cargo run --bin ayeosd
# MEMNET listening on :9876
# commands: matrix, capsule, stats, seed, quit
```

## MEMNET

The MEMNET protocol replaces static IP addressing with intent-based resolution:

- **Address = Context**: geo, role, tags, vector hash — not numbers
- **Capsules**: `.m8` knowledge capsules containing ternary matrices
- **Relevance-aware**: delivery adapts to bandwidth + interest + context
- **LINOSV genesis node**: the root of the ayeOS ternary mesh

## Deterministic seed

Every matrix generated by ayeOS is seeded from the same conversation:
